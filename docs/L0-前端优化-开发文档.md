# L0 控制台前端优化 · 开发文档（交付 Codex）

> 对象：L0 数据底座的运维控制台（`python -m core_data.scripts.dashboard`）。
> 本文档既是**当前已实现基线的规格**，也是**后续扩展任务清单**。Codex 可据此复刻或扩展，无需对话上下文。

## 0. 现状基线

已完成一版重设计（从暗色密集看板 → 干净浅色、可调节控制台）：
- 模板：`src/core_data/scripts/dashboard.html`（由 `dashboard.py::_render_index()` 读取并返回）。
- 静态预览（内置 mock，可独立打开）：`docs/dashboard-preview.html`。
- 后端：`dashboard.py` 提供 `GET /` `GET /api/status` 与 `POST /api/sources|/api/sources/toggle|/api/crawl`。

> **为什么模板单独成文件**：`ruff` 行宽 100，内联大段 HTML 会触发 E501。模板放 `.html`、
> 经 `pyproject` 的 `[tool.setuptools.package-data]` `"core_data.scripts"=["*.html"]` 打包。**保持这一结构**。

## 1. 设计目标与原则

1. **清爽**：浅色为默认、单一强调色、柔和阴影替代硬边框、充足留白。
2. **可调节**：主题（浅/深/系统）、强调色、密度（舒适/紧凑）、自动刷新间隔——全部存 `localStorage`。
3. **数据可视**：面积趋势图 + 投递环形图作为视觉重心。
4. **诚实数据**：只展示后端真实提供的字段；无数据的图表优雅降级（不造假）。
5. **可截图验证**：**禁用无限 CSS 动画**（`animation … infinite`），否则 headless 截图工具会因页面不空闲而超时。

## 2. 设计令牌（CSS variables）

根元素 `<html data-theme data-density style="--accent:…">`。

- 强调色：`--accent`（默认 `#6366f1`），可选 `#8b5cf6/#0ea5e9/#10b981/#f43f5e/#f59e0b`。
- 浅色：`--bg:#f6f7f9 --card:#fff --ink:#0f1729 --muted:#64748b --line:#edf0f4`，语义 `--ok:#10b981 --warn:#f59e0b --bad:#f43f5e --info:#3b82f6`。
- 深色：`--bg:#0a0d13 --card:#10141c --ink:#e8ebf2 --line:#1b212c`，语义略提亮。
- 密度：`comfortable` vs `compact` 调 `--pad/--rowy`。
- 圆角 `--r:16px`，阴影 `--shadow`（细边 + 极轻投影）。

> **深色坑（已踩）**：不要把 `var(--bg)` 放进 `background` 简写的颜色位与渐变并列——某些渲染器不二次求值导致深色失效。**用独立 `background-color: var(--bg)`**。

## 3. 布局与组件

- **顶栏**：Logo「L0 CodePick」｜`＋新增来源`(primary)｜刷新｜主题切换｜设置(齿轮，弹出 pop)。
- **页头**：标题「管道总览」+ 副标题｜右侧 `24h/7d/30d` 分段 + 实时时间戳(脉冲点，**非无限动画**)。
- **KPI 行（4 卡）**：来源 / 原始文档 / 内容项 / 投递率，含图标 chip、主数值、底部小标。
- **图表行**：左=采集量趋势（SVG 面积图，raw+content 双线，峰值）；右=Outbox 投递（环形 + 状态分布图例）。
- **表格行**：左=最近内容（状态筛选 chips + 表）；右=采集来源（头像、doc 数、健康 pip、行内 抓取/启停）。
- **任务表**：最近抓取任务（统计/错误 + 分页 上一页/下一页）。
- **页脚**：版本 + 稳定事件名 + 系统健康。
- **覆盖层**：新增来源 Modal（名称/feed/主页）；Toast；设置 pop（主题/强调色/密度/自动刷新）。

## 4. 交互（全部已实现，需维持）

- 主题切换（顶栏一键 + pop 三选）、强调色色板、密度切换 → 实时套用并存 `localStorage`(key `l0cfg`)。
- 自动刷新：开关 + 间隔(5/10/30/60s)；`setInterval` 拉 `/api/status`。
- 区间 `24h/7d/30d` → 以 `?range=` 重新拉数据。
- 内容状态 chips → 客户端过滤；任务分页 → `?jobs_offset=&jobs_limit=`。
- 来源行 抓取/启停 → `POST /api/crawl|/api/sources/toggle`，Toast 反馈，完成后刷新。
- 新增来源 Modal → `POST /api/sources`。
- 所有用户可见字符串经 `esc()` 防 XSS。

## 5. 图表实现要点

- 趋势图：viewBox 归一坐标 + `preserveAspectRatio="none"`；平滑用 Catmull‑Rom→Bézier（见 `smooth()`）；
  面积渐变 `linearGradient`（accent 透明渐变）；数据点小圆。空数据时 `max=1` 防除零，降级为平线。
- 环形图：两个 `circle` + `stroke-dasharray/dashoffset`，`rotate(-90)`；中心叠加百分比文本。
- 颜色一律取自 CSS 变量（`getComputedStyle().getPropertyValue('--accent')`），保证主题/换色联动。

## 6. 数据契约（消费 `GET /api/status`）

```jsonc
{
  "generated_at":"ISO", "range":"24h",
  "counts":{ "sources","sources_enabled","raw_documents","content_items",
             "content_versions","outbox_events","outbox_published","outbox_pending","delivery_rate" },
  "series":{ "labels":[...], "raw":[...], "content":[...] },
  "status_breakdown":{ "READY":n,"WAIT_FILTER":n,"VARIANT":n,"FAILED":n,"TREND":n },
  "sources":[{ "id","name","feed_url","enabled","doc_count","health","fail_count" /*P3 增 type,interval_min,next_run*/ }],
  "recent_content":[{ "id","title","canonical_url","lang","status" /*P3 增 meta.rank/heat*/ }],
  "recent_jobs":[{ "id","source_id","kind","status","stats","error" }],
  "jobs_page":{ "offset","limit","total","has_prev","has_next" }
}
```
POST：`/api/sources {name,feed_url,home_url}` ·`/api/sources/toggle {id}` ·`/api/crawl {source_id}`。

## 7. 扩展任务（配合多源采集，详见 `L0-多源采集-开发计划.md` P3）

- [ ] **类型专属参数**：根据所选类型动态渲染字段（或一个 JSON 编辑框），随 `POST /api/sources` 的 `crawl_config` 提交。

## 9. 质量门禁
- `python -m ruff check .`（HTML 留在 `.html`，避免 E501）。
- `python -m mypy --config-file pyproject.toml src`（dashboard.py 需通过 strict）。
- 静态预览 `docs/dashboard-preview.html` 与真实模板保持视觉一致（mock 数据），改设计时两者同步。

## 10. 约束 / 注意
- **预览访问**：`dashboard.py` 起的服务监听运行它的机器；编辑器预览面板里的沙箱服务**宿主浏览器访问不到**，要么直接开 `docs/dashboard-preview.html`（静态自包含），要么在本机跑 `dashboard.py`。
- **禁用无限动画**（见 §1.5）。
- **localStorage key**：真实页用 `l0cfg`，静态预览用 `l0cfg_preview`，勿混。
- **不引入前端框架/构建链**：保持单文件原生 HTML/CSS/JS，零依赖、零打包。
